Política de Privacidade

Última actualização: 29 de maio de 2026

📡 O PromoHunter foi desenvolvido com respeito pela privacidade do utilizador. Não vendemos dados a terceiros. Não criamos perfis comerciais. Não usamos publicidade comportamental.

1. Quem somos

O PromoHunter é uma aplicação desenvolvida por Maria Helena Afonso, Lda, com sede em Portugal. A app analisa anúncios de imóveis e veículos usando inteligência artificial e disponibiliza os resultados ao utilizador.

2. Dados que recolhemos

Recolhemos apenas os dados mínimos necessários para o funcionamento da app:

  • Identificador de dispositivo anónimo — gerado localmente no dispositivo, sem ligação à identidade do utilizador. Usado para controlar o limite diário de análises gratuitas.
  • URLs submetidos para análise — os links que o utilizador submete são processados pelo nosso servidor para extrair informação pública do anúncio. Não guardamos o histórico de pesquisas de forma identificável.
  • Dados de utilização agregados — contadores anónimos de uso (número de análises por dia) para gestão do serviço.

3. Dados que NÃO recolhemos

  • Nome, email ou qualquer informação pessoal identificável
  • Localização GPS ou geolocalização precisa
  • Contactos, calendário ou outros dados do dispositivo
  • Dados de pagamento (processados por Google Play)
  • Histórico de navegação fora da app

4. Como usamos os dados

  • Para processar os anúncios submetidos e devolver uma análise com Deal Score
  • Para controlar o limite gratuito de análises por dispositivo
  • Para manter e melhorar o serviço

Não usamos os dados para publicidade comportamental, criação de perfis, ou partilha com terceiros para fins comerciais.

5. Partilha de dados com terceiros

Para fornecer o serviço de análise com IA, os URLs e o conteúdo público dos anúncios são enviados para:

  • OpenRouter / Meta Llama — para processamento de linguagem natural e análise do anúncio. Consulta a política de privacidade em openrouter.ai/privacy
  • Google Apps Script — para alojamento do backend da app. Consulta a política em policies.google.com/privacy

Não partilhamos dados com anunciantes, corretores ou portais imobiliários.

6. Armazenamento e segurança

O identificador de dispositivo é guardado localmente no dispositivo (localStorage). Os dados de utilização são guardados numa Google Spreadsheet privada com acesso restrito ao operador da app. Não há base de dados com informação pessoal identificável.

7. Retenção de dados

Os dados de utilização (contadores anónimos) são mantidos por um máximo de 90 dias. Os deals analisados no feed público são mantidos por 30 dias. O identificador de dispositivo pode ser eliminado a qualquer momento limpando os dados da app.

8. Direitos do utilizador (RGPD)

Ao abrigo do Regulamento Geral de Proteção de Dados (RGPD), tens direito a:

  • Aceder aos dados associados ao teu identificador de dispositivo
  • Solicitar a eliminação dos teus dados
  • Opor-te ao tratamento dos teus dados

Para exercer estes direitos, contacta-nos em privacidade@promohunter.pt

9. Anúncios

A versão gratuita da app inclui anúncios servidos pelo Google AdMob. O AdMob pode usar o identificador de publicidade do dispositivo para mostrar anúncios relevantes. Podes desactivar os anúncios personalizados nas definições do teu dispositivo Android em Definições → Google → Anúncios. A versão Pro não inclui anúncios.

10. Crianças

O PromoHunter não é dirigido a menores de 13 anos. Não recolhemos conscientemente dados de crianças.

11. Alterações a esta política

Podemos actualizar esta política periodicamente. Quando o fizermos, actualizaremos a data no topo desta página. Alterações significativas serão comunicadas através da app.
